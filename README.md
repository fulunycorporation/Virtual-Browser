# Virtual Browser — твой компактный браузер на Electron

![Virtual Browser Logo](logo.png)

**Virtual Browser** — это лёгкий браузер с вкладками, настройками и встроенной системой загрузок, собранный на Electron. Это первая бета-версия: проект создан для тестирования, сбора фидбека и быстрого развития вместе с сообществом.

## ✨ Что умеет

- **Вкладки** — открывай сколько угодно страниц, переключайся между ними.
- **Панель закладок** — быстрый доступ к любимым сайтам.
- **Настройки интерфейса**:
  - Тёмная/светлая тема.
  - Масштаб страниц (от 50% до 200%).
  - Свой фон стартовой страницы (по ссылке или цветом).
- **Система загрузок** — выбирай папку для сохранения, следи за прогрессом, получай уведомление об окончании.
- **Минималистичный дизайн** — ничего лишнего, только то, что нужно.

> ⚠️ Это бета-версия. Возможны мелкие баги, нестабильность при работе с тяжёлыми сайтами и другие особенности. Всё это мы будем править в следующих обновлениях.

## 🚀 Как установить

1. Скачай установщик из раздела [Releases](https://github.com/ТВОЙ_НИК/virtual-browser/releases).
2. Запусти `Virtual Browser Setup 1.0.0.exe`.
3. Следуй инструкциям на экране.
4. На рабочем столе появится ярлык — запускай и пользуйся!

### ⚠️ Важно: предупреждение Windows (SmartScreen)

При первом запуске установщика Windows может показать экран **«Система защитила ваш компьютер»**. Это происходит из-за отсутствия платной подписи кода — так бывает у всех самописных приложений.

**Что делать:**
1. Нажми **«Подробнее»**.
2. Кликни **«Выполнить в любом случае»**.
3. Продолжай установку как обычно.

Это безопасно: исходный код открыт здесь, в репозитории, и ты можешь сам его проверить.
